# LeonahJani_Portfolio

Create a high-fidelity, modern, responsive personal portfolio website UI/UX design for Leonah Jani, a professional Digital Marketer, Graphic Designer, Product Designer, and Creative Professional.

The website should feel premium, modern, creative, professional, feminine without being overly decorative, and technology-focused. Use a clean vertical scrolling portfolio structure with strong visual hierarchy, generous white space, minimalist grids, subtle shadows, rounded cards, and sophisticated typography.text in lime green buttons should be white text color throughout the design

OVERALL DESIGN SYSTEM

Primary Color: Vibrant Lime Green #32CD32

Secondary Colors: White #FFFFFF, Deep Charcoal #171717, Soft Grey #F4F4F4

Accent: Darker green shades may be used sparingly for hover states and visual depth.

Typography:

Hero headline: Playfair Display, bold

Section headings: modern bold sans-serif

Body text: clean modern sans-serif such as Inter, Poppins, or Manrope

Strong contrast and excellent readability

Visual Style:

Minimalist editorial portfolio

Modern creative-tech aesthetic

Premium agency-style presentation

Clean asymmetric grids

8–12px rounded corners

Soft realistic shadows

Subtle glassmorphism only where appropriate

Crisp UI cards

High-quality 3D character illustrations

Consistent lime-green visual identity

Responsive desktop-first composition

Professional spacing and alignment

Avoid clutter, excessive gradients, excessive decoration, or childish visuals
